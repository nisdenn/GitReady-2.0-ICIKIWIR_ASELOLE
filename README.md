# BNCC — Bina Nusantara Computer Club

Website landing page interaktif untuk BNCC (Bina Nusantara Computer Club), menampilkan profil organisasi, program pembelajaran, event, dan tim. Dibuat sebagai study case kolaborasi tim menggunakan Git & GitHub pada Workshop Git Ready 2.0.

---

![Screenshot](link-screenshot-kamu.png)

Live Demo: https://git-ready-2-0-icikiwir-aselole.vercel.app/

---

## Tech Stack

- HTML5
- CSS3
- JavaScript (Vanilla)
- Git & GitHub

---

## Fitur Utama

- [x] Dark mode premium dengan accent biru
- [x] Animated stat counter (2000+ Members, 50+ Events, 15+ Years)
- [x] Scroll reveal animation pada setiap section
- [x] Interactive 3D tilt effect pada program cards
- [x] Cursor glow effect (desktop)
- [x] Responsive navbar dengan hamburger menu
- [x] Button ripple effect on click
- [x] Smooth scroll navigation
- [x] Fully responsive layout (mobile, tablet, desktop)
- [x] Typewriter effect pada hero badge

## How to Run

1. Clone repository ini:

   ```bash
   git clone https://github.com/nisdenn/GitReady-2.0-ICIKIWIR_ASELOLE.git
   ```

2. Buka folder hasil clone, lalu klik dua kali file `index.html` (atau klik kanan → Open with → Browser).
